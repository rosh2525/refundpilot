# Demo script — target 2 minutes 45 seconds

Only record the sandbox version after passing the real integration smoke test. Use a live configured Gemini model and actual PayPal sandbox activity. Keep a fresh captured payment ready, then show the capture ID and result in the video.

## 0:00–0:20 — The problem
"A refund is a financial decision, but the information is scattered. RefundPilot brings the customer's request, the merchant's policy, and the payment into one clear review."

## 0:20–0:45 — Original payment and request
Show a real $20 captured sandbox purchase. Open **New request**, paste the fictional damaged pen-holder message, and request $5. Briefly show that this is the original capture, not a fabricated transaction.

## 0:45–1:15 — AI and evidence
Analyze the request. Show the actual model source, concise recommendation, and exact policy/customer citations. Point out the independent amount, currency, window, and balance checks.

## 1:15–1:45 — Human approval and refund
"The AI cannot move funds. I approve this exact $5 amount." Check the confirmation and approve. Show the operation result and refund ID. If it remains pending, say so; never relabel it as completed. Show authoritative sandbox activity and the updated $15 refundable balance when confirmed.

## 1:45–2:15 — Controls
Show an over-refund request being blocked. Explain that duplicate clicks return the same operation and uncertain network responses reuse the same request UUID. Keep technical explanation short and legible.

## 2:15–2:35 — The paper trail
Open Refund history and Audit trail. Show the actual verified payment/refund events and recorded approval.

## 2:35–2:45 — Close
"Evidence-backed recommendations. Human-approved execution. A complete paper trail. That's RefundPilot."

Record at readable resolution, use original narration, and omit unlicensed music/assets. Upload to YouTube with public visibility. The final video must be under three minutes.
